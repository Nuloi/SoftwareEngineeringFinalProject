# 소프트웨어 공학 2026 기말 팀 프로젝트

## 1. 개요

- **장르**: 텍스트 기반 턴제 RPG
- **핵심 루프**: 던전 진입 → 랜덤 이벤트(전투 / 상점 / 선택지) 반복 → 보스전 → 다음 스테이지
- **우선 구현 범위**: 전투, 던전, 상점

```
[마을/시작] → [스테이지 1: 이벤트 N회 → 보스] → [스테이지 2: ...] → ... → [엔딩]
```

## 2. 전투 시스템

쯔꾸르(RPG Maker) 스타일의 턴제 커맨드 전투.

### 2.1 커맨드

| 커맨드 | 설명 |
|--------|------|
| **공격** | 기본 공격. MP 소모 없음 |
| **스킬** | MP를 소모해 강한 공격 / 회복 / 버프 사용 |
| **방어** | 이번 턴 받는 데미지 감소 (예: 50%) |
| **아이템** | 인벤토리의 소모품 사용 (포션 등) |


### 2.2 턴 진행

1. 플레이어 커맨드 선택
2. 속도(SPD) 비교로 행동 순서 결정
3. 행동 처리 → 결과 출력
4. 승패 판정 (HP 0 체크)
5. 다음 턴

### 2.3 스탯

| 스탯 | 설명 |
|------|------|
| HP | 체력. 0이 되면 사망 |
| MP | 스킬 사용 자원 |
| ATK | 공격력 |
| DEF | 방어력 |
| SPD | 행동 순서 결정 |

### 2.4 데미지 공식 (초안)

```
데미지 = max(1, ATK - DEF / 2) × 랜덤(0.9 ~ 1.1)
방어 중이면 데미지 × 0.5
```


### 2.5 전투 보상

- 경험치 → 레벨업 시 스탯 상승
- 골드 → 상점에서 사용
- 낮은 확률로 아이템 드롭

### 2.6 출력 예시

```
=== 슬라임이 나타났다! ===
[용사] HP 50/50  MP 20/20
[슬라임] HP 30/30

1. 공격  2. 스킬  3. 방어  4. 아이템
> 1
용사의 공격! 슬라임에게 12의 데미지!
슬라임의 공격! 용사에게 3의 데미지!
```

## 3. 던전 시스템

### 3.1 구조

- 던전은 여러 **스테이지**로 구분
- 한 스테이지 = **한 사이클**
- 사이클: 랜덤 이벤트 N회 반복 → 마지막에 **보스전**

```
스테이지 1
 ├─ 이벤트 1 (랜덤)
 ├─ 이벤트 2 (랜덤)
 ├─ ...
 ├─ 이벤트 N (랜덤)
 └─ 보스전
```

### 3.2 랜덤 이벤트 종류

| 이벤트 | 내용 | 확률 (초안) |
|--------|------|-------------|
| **전투** | 스테이지에 맞는 일반 몬스터와 전투 | 60% |
| **상점** | 떠돌이 상인 등장, 아이템 구매/판매 | 15% |
| **선택지** | 텍스트 이벤트, 선택에 따라 보상 또는 페널티 | 25% |

### 3.3 선택지 이벤트 예시

```
낡은 상자를 발견했다.
1. 연다
2. 무시하고 지나간다
```
- 1 선택 → 50%: 골드 획득 / 50%: 함정(HP 감소) 또는 미믹 전투
- 2 선택 → 아무 일 없음

### 3.4 사망 처리 

- 마을로 귀환, 골드 일부 손실

## 4. 상점 시스템

### 4.1 등장 위치

- 마을 상점 (스테이지 사이)
- 던전 내 랜덤 이벤트 (떠돌이 상인)

### 4.2 기능

- **구매**: 골드로 아이템 구매
- **판매**: 보유 아이템을 일정 비율(예: 50%) 가격에 판매

### 4.3 아이템 목록 (초안)

| 아이템 | 종류 | 효과 | 가격 |
|--------|------|------|------|
| 포션 | 소모품 | HP 30 회복 | 20G |
| 하이포션 | 소모품 | HP 80 회복 | 50G |
| 에테르 | 소모품 | MP 20 회복 | 30G |
| 철검 | 장비(무기) | ATK +5 | 100G |
| 가죽갑옷 | 장비(방어구) | DEF +3 | 80G |

### 4.4 출력 예시

```
=== 상점 ===  보유 골드: 120G
1. 포션 (20G)
2. 에테르 (30G)
3. 철검 (100G)
0. 나가기
>
```
